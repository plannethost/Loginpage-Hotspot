INFORMASI LAYANAN

Temukan jawaban atas pertanyaan umum seputar layanan internet kami.


Internet Hotspot 6
  • Bagaimana cara menggunakan layanan internet hotspot kami?
    •
  • Pastikan area Anda tercover dengan signal WiFi kami

  • Untuk menikmati layanan WiFi kami, Anda harus membeli kode voucher yang akan digunakan untuk verifikasi/login ke jaringan. Kami menyediakan pilihan voucher WiFi sesuai kebutuhan Anda

  • Aktifkan wireless pada smartphone/laptop dan hubungkan dengan SSID WiFi kami

  • Tunggu pop-up login muncul. Jika tidak, buka browser (Chrome/Firefox) dan ketik manual URL halaman login yang tertera di voucher

  • Pada halaman login, masukkan ID VOUCHER dan klik Login
  • Apa yang harus dilakukan saat muncul "Kode voucher salah"?
    •
  • Pastikan penulisan ID VOUCHER tepat (perhatikan huruf besar/kecil)

  • Hindari spasi sebelum/sesudah kode

  • Kenapa muncul "Voucher sudah dipakai" dan bagaimana solusinya?
    •
  • 1 kode voucher hanya bisa dipakai di 1 perangkat (kecuali paket Internet Rumah)

  • Jika ingin pindah perangkat, lakukan logout manual terlebih dahulu

  • Pastikan tidak ada orang lain yang menggunakan voucher Anda

  • Apakah Voucher bisa di beli online?
    •
  • Bisa, Silahkan salin link di bawah kemudian akses di browser favorit anda. https://client.planetmn.com/e-voucher
  • Apakah Kode Voucher Bisa di tunda?
    •
  • Kode voucher dapat di tunda sesuai dengan paket yang di beli, untuk mengetahui expired paket tersebut, cek dengan url hotspot yang ada di label kode voucher

  • Apa saja metode pembayaran yang tersedia?
    •
  • Transfer bank, kartu kredit,Virtual Accounr, gerai pembayaran (Alfamart, Indomaret), atau auto-debit.


Internet Rumah 5
  • Apa Itu Paket Internet Rumah?
  • Paket internet rumah adalah layanan internet berlangganan yang dirancang untuk penggunaan di rumah, biasanya dengan kuota unlimited, kecepatan stabil, dan harga terjangkau dibanding paket internet Hotspot.

  • Bisa di gunakan berapa perangkat?
  • Paket internet rumah tidak di batasi untuk perangkat karna internet rumah hanya membatasi kecepatan internetnya

  • Bagaimana cara berlangganan Internet Rumah?
  • Anda bisa mendaftar melalui halaman Internet Rumah dan memilih paket sesuai kebutuhan.

  • Bisa langsung menghubungi teknisi lapangan

  • Apa saja persyaratan untuk berlangganan?
    •
  • Foto Kartu identitas

  • Nama Pengguna

  • Nomor Telpon

  • Alamat Email

  • Alamat Pemasangan

  • Apa saja metode pembayaran yang tersedia?
    •
  • Transfer bank, kartu kredit,Virtual Accounr, gerai pembayaran (Alfamart, Indomaret), atau auto-debit.


Cloud Storage 2
  • Apa itu cloud storage?
  • Cloud storage adalah layanan penyimpanan data online yang memungkinkan pengguna menyimpan, mengakses, dan mengelola file melalui internet tanpa perlu media fisik seperti hard disk atau flash drive.

  • Apa keuntungan menggunakan cloud storage dibanding penyimpanan lokal?
    •
  • Akses dari mana saja: File bisa dibuka di perangkat apa pun dengan internet.

  • Backup otomatis: Meminimalkan risiko kehilangan data.

  • Berbagi mudah: File bisa dibagikan dengan orang lain secara instan.

  • Skalabilitas: Kapasitas penyimpanan bisa ditambah sesuai kebutuhan.
