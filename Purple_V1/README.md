# Purple_V1

Versi pertama dari template login hotspot yang ada di repository ini. Desainnya lebih sederhana, ringan, dan cocok untuk kebutuhan hotspot dasar.

## Fokus Utama

Folder ini berisi template halaman yang umum dipakai pada portal login hotspot, seperti:

- halaman login
- halaman status
- halaman logout
- halaman FAQ
- halaman bantuan
- halaman error

## File Utama

- `login.html` — form login utama
- `status.html` — halaman status pengguna hotspot
- `logout.html` — halaman logout
- `faq.html` — halaman FAQ
- `help.html` — halaman bantuan
- `error.html` — halaman error
- `md5.js` — script hashing/keamanan tambahan
- `api.json` — konfigurasi data atau API pendukung
- `assets/` — aset pendukung seperti gambar, ikon, dan style tambahan

## Cara Pakai

1. Salin isi folder `Purple_V1` ke direktori yang dapat diakses oleh client hotspot.
2. Sesuaikan teks, warna, logo, dan struktur HTML sesuai jaringan Anda.
3. Hubungkan halaman login hotspot dengan konfigurasi router atau web server yang dipakai.
4. Uji login dan status pengguna sebelum digunakan di lingkungan produksi.

## Catatan

Versi ini cocok untuk kebutuhan yang lebih minimal dan cepat diimplementasikan. Untuk tampilan yang lebih modern dan lengkap, lihat folder `premium-v4`.
