Pusat Bantuan

Panduan penggunaan dan solusi masalah umum

Menggunakan Voucher

Masukkan kode voucher yang Anda beli di kolom "Voucher" pada halaman login, lalu tekan Masuk. Kode voucher berlaku untuk satu kali pemakaian sesuai durasi yang tertera.

Ke Halaman Login

Login sebagai Member

Gunakan username dan password yang telah didaftarkan. Jika belum punya akun, hubungi admin untuk mendaftar.

  • Buka tab Member di halaman login.
  • Masukkan username & password.
  • Klik Masuk.

Lupa Password?

Jika Anda lupa password akun member, segera hubungi admin untuk mereset password Anda. Siapkan data pendukung untuk verifikasi.

Masalah Koneksi

Jika internet tidak berfungsi setelah login, coba langkah berikut:

  • Restart perangkat Anda.
  • Lupakan jaringan WiFi lalu sambungkan kembali.
  • Bersihkan cache browser.
  • Jika masih bermasalah, hubungi admin.

Kuota & Durasi

Cek sisa kuota dan waktu Anda melalui halaman Status setelah login. Halaman ini menampilkan pemakaian data, lama koneksi, dan sisa waktu aktif.
